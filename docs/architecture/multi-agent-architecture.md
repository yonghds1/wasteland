# 多Agent协作架构文档

本文档描述 wasteland (RxJS-first TypeScript Agent CLI) 的多Agent协作架构设计。

## 概述

wasteland 采用 **Agents-as-Tools** 模式实现多Agent协作，核心思想是将子Agent作为一个工具（spawn_agent）注册到工具注册表中，主Agent通过调用该工具来创建和管理子Agent。

### 关键 RxJS 操作符

| 操作符 | 用途 |
|--------|------|
| `defer` | 延迟执行，创建 Observable 时才执行函数体 |
| `concat` | 顺序拼接多个 Observable |
| `concatMap` | 对每个值映射为 Observable，顺序订阅 |
| `tap` | 执行副作用（如记录追踪），不改变流 |
| `map` | 转换值 |
| `from` | 将 Promise/Iterable 转换为 Observable |
| `of` | 创建发出单个值的 Observable |

## spawn_agent 工具参数

```typescript
type SpawnAgentInput = {
  /** 子 Agent 标识 */
  name: string;
  /** 任务描述 */
  task: string;
  /** 可选：模型选择（haiku/sonnet/opus 或具体模型名如 qwen-max） */
  model?: string;
  /** 可选：限定工具集 - 限制子 Agent 可用的工具列表 */
  tools?: string[];
  /** 可选：是否继承父 Agent 的历史上下文，默认 false */
  inheritHistory?: boolean;
};
```

### 模型映射

| 通用名称 | Qwen | Ollama |
|----------|------|--------|
| `haiku` | qwen-turbo | llama3.2:1b |
| `sonnet` | qwen-plus | llama3.2 |
| `opus` | qwen-max | llama3.3:70b |

### 使用示例

```typescript
// 限制子Agent只能使用 read-file 工具
spawn_agent({
  name: "reader",
  task: "分析配置文件",
  tools: ["read-file"]
})

// 为子Agent选择快速模型
spawn_agent({
  name: "quick-analyzer",
  task: "快速检查",
  model: "haiku"  // qwen -> qwen-turbo
})

// 继承历史上下文，让子Agent了解之前的对话
spawn_agent({
  name: "context-aware-agent",
  task: "继续之前的任务",
  inheritHistory: true
})

// 组合使用
spawn_agent({
  name: "coder",
  task: "实现用户认证模块",
  model: "opus",  // 使用最强模型
  tools: ["read-file", "edit-file", "bash"],  // 限制工具范围
  inheritHistory: true  // 继承对话历史
})
```

## 设计原则

### 1. Agents-as-Tools 模式

- spawn_agent 作为普通工具注册到 ToolRegistry
- 无需修改核心架构即可支持多Agent
- 利用现有权限系统控制 spawn 行为

### 2. 响应式编程 (RxJS)

- 用户输入、Provider响应、工具调用都是 Observable
- 使用 defer 延迟执行，concat 顺序拼接
- 天然支持流式处理和可取消操作

### 3. 递归循环模式

```
defer(() => {
  // 检查条件
  // 执行 Provider
  // 处理事件
  // continuation$ (递归或结束)
})
```

### 4. 可变状态模式

在 concatMap 内部通过 tap 更新状态变量，确保工具执行结果能正确累积到状态中。

## 后续优化方向

1. **并行 spawn_agent** - 当前为顺序执行，可优化为并行执行
2. **嵌套子Agent** - 支持子Agent再spawn更深层级的Agent
3. **Session Resume** - 恢复中断的会话
4. **MCP 集成** - 扩展工具来源
